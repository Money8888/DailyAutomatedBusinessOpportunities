### TOP1｜「指尖星图」—— 把那一刻的真实星空带回家

**一句话概述**：输入任意"时间+地点"（出生瞬间/求婚时刻/毕业晚会/孩子到家的那一夜），AI 调用天文历算精准重建该刻真实星空，生成可交互网页星图 + 实体挂画/亚克力灯罩/黄铜蚀刻板，把"那一刻的宇宙指纹"做成可触摸的礼物。

**自动化机制**：前端时间地点选择器 → Python `skyfield`/`astropy` 精确星历计算（含行星/彗星/流星雨/月相/银河位置） → Three.js 渲染可旋转缩放交互星图 → 可选叙事层（该夜天文事件诗意文案） → 模板化导出 SVG/高清图/交互网页链接 → 对接 POD 挂画/亚克力灯罩/黄铜蚀刻板 API 下单直发；数字版9.9 元预览，实体版69-399 元。

**操作描述**：选时间地点 → AI 计算真实星空 → 选材质（高清单图/亚克力灯罩/黄铜蚀刻板/大幅挂画） → 数字版即时下载或实体版下单 → 收货后扫码回看该夜真实星图。

**合法性**：纯天文计算 + 用户主动输入的纪念节点，无爬虫/无定位采集/无医疗/无金融/无迷信（明确不做星座运势）；AI 仅用于生成诗意文案与排版，标注"AI 协助生成"；实体走正规 POD 渠道；无自动发布行为。

**迭代方向**：与"缘分地图""个人纹章工坊"组合成"人生高光实体化"产品家族；推出婚礼星空签到台/宝宝出生星图/月度天象日历订阅；与天文馆/天文博主合作分销；扩展为"那天的月亮/那天的银河"等单一星体专属款。

### TOP2｜「个人纹章工坊」—— 名字与故事铸成只属于你的徽章

**一句话概述**：输入名字/人生关键词/价值观/家族典故 → AI 按纹章学规则（盾型/分割/色金法/纹饰/托架/箴言）生成唯一纹章 → 导出矢量/3D 模型 → 对接金属徽章/印戒/蜡印章/亚克力立牌/刺绣贴布 POD 直发，把"身份认同"做成可佩戴/可盖印/可传承的实体符号。

**自动化机制**：结构化问卷（关键词/人生高光/家族符号/偏好色系/使用场景） → 纹章学规则引擎（盾面分割/九种金属色/皮草色/常用纹饰库/纹章术语校验） → LLM 生成纹章释义文案（每个元素的象征意义） → SVG/STL 矢量化输出 → 自动适配多工艺模板（冲压徽章/失蜡铸造印戒/激光雕刻蜡印/刺绣贴布/亚克力立牌） → 对接供应链 API 下单。

**操作描述**：填问卷 → AI 生成 3 套纹章方案 → 选 1 套深化 → 选工艺（亚克力立牌 89 元/冲压徽章 129 元/失蜡铸造印戒 399 元/刺绣徽章 159 元） → 下单 → 收货后可用于领证/婚礼请柬/家族信封封蜡/CP 信物。

**合法性**：纯设计生成 + 实体制造，无贵金属投资/无金融属性/无宗教/无迷信；纹章为原创设计（基于用户输入），与现存家族纹章仅灵感相似而非照搬，不涉及侵权；印章/印戒明确标注"私人玩具/装饰品，非公章/非公文印"；用户输入数据最小必要、可删除。

**迭代方向**：推出"家族纹章 + 个人纹章"套装（CP/亲子同款）；与婚礼策划/成人礼机构合作批量定制；推出"年度纹章"订阅（生肖/星座/年主题）；开放纹章设计师分成平台扩展 SKU。

### TOP3｜「缘分地图」—— 双轨汇聚的相遇证据可视化

**一句话概述**：情侣/挚友/母女/父子各自输入"相识前的生活轨迹点"（老家/学校/公司/常去地） → AI 生成双轨迹时空汇聚动画（两条线随时间延伸最终交汇） + 实体双面地图挂画/亚克力立牌/翻页书，把"相遇的必然性"做成可触摸的视频与海报。

**自动化机制**：双人协作表单（地点 + 时间段 + 情感标签，可同时异地线上协作） → 高德/百度地图 API 逆地理编码 + 路径规划 → LLM 生成"平行时空独白"文案（双方各自在那个时间点不知道对方存在） → After Effects 模板/Remotion 程序化渲染双轨迹汇聚动画（含时间轴/心跳节奏/关键节点弹窗） → 同素材自动排版双面地图海报（正面轨迹线/背面关键节点卡片） → POD 印刷/亚克力切割直发。

**操作描述**：建档 + 邀请对象协作填写 → AI 生成 60 秒双轨迹汇聚动画 + 实体地图海报预览 → 选数字版（29 元）或实体版（59-199 元：双面海报/亚克力立牌/翻页书） → 下单 → 收货后朋友圈/领证现场播放。

**合法性**：仅处理用户主动填写的公开地点与时间，无后台定位采集/无通讯录读取/无人脸；动画为程序化生成非深度伪造；标注"艺术化呈现，非精确轨迹复刻"；地图 API 走正规开放平台；双人协作数据经双方确认上传。

**迭代方向**：扩展为"三人/家族"多轨迹汇聚；推出"相遇十周年/银婚/金婚"纪念版；与婚礼策划/婚礼纪合作领证现场播放；扩展"相遇那天的天气/那天的新闻头条"叠加信息层。

### TOP4｜「香氛配方卡」—— 记忆气味的可闻化还原（数字版 + DIY 原料推荐）

**一句话概述**：用文字/语音描述"记忆中的味道"（奶奶厨房/初恋图书馆/童年松林/婚礼当天） → AI 调香大模型拆解前中后调 + 输出标准配方卡（含精油/香精/基底油比例/调香师手记） + 合规原料推荐清单 + 安全使用说明 → 用户可自行 DIY 或购买套件，把"无形气味"做成可闻可赠的实体。

**自动化机制**：自然语言/语音描述 → 微调调香 LLM（含 IFRA 国际香料协会标准 / 中国化妆品原料白名单 / 香料特性 / 协同矩阵） → 输出标准配方单（百分比/滴数/安全浓度/过敏原标注） → 自动生成配方卡排版（视觉化金字塔/调香师手记/使用建议） → 对接合规原料供应商 SKU 直链（1688/京东自营）；数字版配方卡 9.9 元，原料套件包 39-89 元（不含已调制成品，规避化妆品备案合规门槛）。

**操作描述**：描述气味记忆 → AI 生成 3 版配方卡 → 数字版 9.9 元解锁高清 → 推荐合规原料 → 可 DIY 或购买原料套件 → 制作过程分享至小红书/朋友圈。

**合法性**：仅提供"配方建议 + 合规原料推荐"，不直接生产/销售成品香水/香精；用户按配方自购原料自调属于个人 DIY 范畴；所有原料均标注 IFRA 安全浓度上限与过敏原警告；产品页明确"本配方为艺术创作参考，非专业调香师认证结果"，不宣称功效/疗愈/医疗；无化妆品生产/销售/代加工环节，规避《化妆品监督管理条例》监管；用户描述为创作输入，无生物特征采集。

**迭代方向**：扩展"城市气味图鉴"系列（上海弄堂/北京胡同/广州茶餐厅）；上线"季度香气"订阅（每月一封气味信件）；与气味博物馆/小红书气味博主合作分销；推出"情侣双瓶香"（双方各调一瓶融合）。

### TOP5｜「植物视角日记」—— 绿植的第一人称成长档案

**一句话概述**：拍一张绿植照 → AI 识别品种/生长阶段/健康度 → 以植物"第一人称"生成周更成长日记（含情绪化独白/养护贴士/环境感知），累积成季度实体观察手账寄送，把"养植物"变成"陪一个生命写传记"。

**自动化机制**：用户上传照片 → 植物识别 API（Plant.id / 自训练 YOLO 模型） → 结合 EXIF/天气/光照/浇水记录 → LLM 生成植物人设口吻周记（如"本周叶片展开 2cm，感谢主人在周三给的雾化；本月光照不足，我有点徒长，建议南窗挪两小时"）+ 养护待办卡 → 程序化排版周卡/月报/季度手账 → POD 印刷装订寄送；可选接入智能花盆传感器（米家土壤湿度/光照）自动同步数据；订阅制 19.9-39.9 元/月，季度实体手账 69 元/季。

**操作描述**：拍一张绿植照 → 录入植物昵称 → 每周上传 1-2 张照片 → 收到周更"植物视角日记" → 季度末收到实体手账 → 见证植物成长全过程。

**合法性**：纯园艺科普 + 情感化表达，无医疗/心理诊断；植物人设明确标注"AI 拟人化创作"，不构成拟人化陪伴违规；照片会话级处理可删除；不涉及活体植物交易/检疫；养护建议属通用园艺常识，不构成专业园艺师服务；订阅自动续费按《电子商务法》明确告知。

**迭代方向**：扩展"多肉/食虫植物/水草"等细分品类专属口吻模板；与植物园/园艺博主合作推出"全国植物视角地图"；上线"植物生日"纪念册（首株植物到家的那天）；接入智能花盆硬件打赏销售。
