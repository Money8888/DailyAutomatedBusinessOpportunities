## TOP1｜「指纹诗笺」—— 把指纹里藏的诗，印成你唯一的一封信

**一句话概述**：用指尖在屏幕上划一道纹路，AI 沿指纹脊线生成一首视觉诗（诗行随纹路流动、分叉、汇聚），活版印在棉纸/宣纸上，火漆封缄寄出——把"世界上唯一的你"写成"世界上唯一的诗"。

**自动化机制**：前端 Canvas 采集指纹轨迹 → OpenCV 提取脊线拓扑 → LLM 按拓扑结构生成诗行（脊线长=句长、分叉=转折）→ 程序化排版贴合脊线 → 矢量文件对接活版/凸印/烫金工艺 + 火漆封装直发。

**操作描述**：手机划一下指纹 → 选"给未来的我/给暗恋对象/给已故亲人/给宠物"场景模板 → 生成专属视觉诗 → 数字版 9.9 元即时下载，实体活版信笺+火漆套装 69-159 元寄送。

**合法性**：指纹仅作创作参数，即用即删、不存储不比对（不构成生物识别应用，规避《个人信息保护法》敏感信息红线）；活版印刷为普通印刷服务；AIGC 内容加显式标识。

**迭代方向**：婚礼誓言版（双指纹交叠成诗）、出生纪念版、悼念版等场景化高客单 SKU；火漆印章可选指纹纹路/生肖/星座定制。

## TOP2｜「祖先视角穿越日记」—— 让曾祖父"开口"讲那年的事

**一句话概述**：用户提供家谱、老照片和口述素材，AI 生成祖先第一人称的"穿越日记"（按年代、方言、大事件还原他的所见所感），排版成复古线装书寄送，199-699 元/本，清明/寿宴/家族聚会的顶级情感礼。

**自动化机制**：结构化问卷（年代/籍贯/大事件/家族轶事）→ RAG 检索本地史志与方言语料 → LLM 以祖先口吻、认知局限生成全年日记（含天气/物价/心境）→ 古籍排版引擎（竖排/繁体/朱砂批注/宣纸纹理）→ 对接线装书工厂 POD 直发。

**操作描述**：填问卷+传老照片 → 选年代与家族故事 → 生成"曾祖父眼中的 1937 年冬天"式日记 → 线装书直发到家，附"AI 生成·家族纪念品"说明页。

**合法性**：素材为用户自有/公共历史，不克隆任何真人声音（无声音权风险）；明示"AI 艺术创作，非史实记载"；非遗嘱、非拟人化陪聊；AIGC 加标识。

**迭代方向**：家族迭代复购（新增祖先/后代）、节点礼赠（寿诞/祭祖/婚嫁）、分支族人各执一册的多册分发；可加"一页家训笺"轻量版引流。

## TOP3｜「味觉配色师」—— 把"草莓味的初恋"调成一盒真能画画的颜料

**一句话概述**：上传一段记忆、一种心情或一张照片，AI 按联觉通感拆解出 5 色"味觉色板"（含潘通色号+风味描述+混色配方），配套真能画画的颜料/墨水套装——把抽象感觉变成可触摸的创作工具。

**自动化机制**：多模态理解输入 → LLM 按联觉框架生成 5 色味觉色板 → 参数化生成颜料配方单（颜料索引/填充重量/安全成分表）→ 对接 1688 定制灌装供应商小批量生产直发；数字版色卡 9.9 元，实体套装 59-129 元。

**操作描述**：说一句"草莓味的初恋"或传一张照片 → 生成专属味觉色板 → 下载数字色卡，或下单实体颜料套装（盒盖内印风味小故事）。

**合法性**：纯美术材料销售，非食品/化妆品/医疗器械，无需特殊资质；颜料成分严选符合国标的安全原料并做标签合规；AIGC 色卡加标识。

**迭代方向**：季度限定"味觉色盲盒"、美术馆联名色、美术生考级配色包；实体履约绑定可靠灌装供应商后规模化。

## TOP4｜「噪音户口本」—— 给你家的声音办一本户口

**一句话概述**：录 8 段 15 秒的家里日常噪音——冰箱的嗡、老木门的吱、洗衣机脱水最后那一下、楼上邻居的拖椅子、以及一段说不清是什么的怪声——AI 为每段声音出"住户档案卡"（名字、频谱纹身、性格、作息、邻里关系图），装订成《本户声音居民名册》。

**自动化机制**：纯音频 DSP 全自动：提取主频/谐波/节律周期/包络形状 → 映射到"性格轴"（急躁/慵懒/守时/神秘）与"作息推断" → 频谱转 SVG 纹身图 → 命名器由主频段+节律型组合生成（如"低频·守时·嗡先生"）→ 邻里关系图按频段重叠度自动连线 → 排版出册对接印刷 API。前端强制人声检测，检出说话即拒收。

**操作描述**：在家录 8 段日常噪音 → 每段声音自动领到"户口"（名字+性格+作息+邻里关系）→ 数字版 19.9 元/实体册 59-99 元，搬家时这是唯一能带走的房子。

**合法性**：只处理设备/环境噪音，前端人声检测拒收人声（彻底规避声音权/克隆红线）；录音即处理即删，仅保留导出的图形参数；不生成任何语音、不合成人声；AIGC 加标识。

**迭代方向**：租房党"搬家纪念"场景、情侣合住纪念、宠物家庭"家里的声音全家福"；可扩展"新家第一周声音档案"服务。

## TOP5｜「今日怪癖电子宠物」—— 把你的小毛病养成一只会进化的宠物

**一句话概述**：把"早睡""喝够水""今天不刷手机 1 小时"设成一只宠物，每完成一次怪癖它就长大、进化出专属形态，连续坚持解锁稀有外观——把反人性的自律变成想玩的养成游戏。

**自动化机制**：本地/轻后端记录每日怪癖打卡 → 成长值累加，达阈值触发形态进化（可配置的 SVG/像素精灵序列）→ 连续天数解锁稀有外观 → 皮肤/配饰内购 + 订阅变现。

**操作描述**：把"早睡"设成一只小怪兽 → 每晚 11 点前睡它就进化一阶 → 连击 7 天解锁稀有皮肤 → 为它买帽子、买配饰，或订阅解锁更多进化线。

**合法性**：纯行为游戏化工具，不碰资金归集、不做心理/医疗疗效宣称；用户自主填写数据，无敏感信息采集；内购按平台规则明示。

**迭代方向**：多宠物/多怪癖并行养成、好友对战、节气限定宠物；与"攒钱副本"类目标管理形成产品矩阵。

## TOP6｜「嘴替·关系科」—— 那句说不出口的话，AI 帮你写成五个版本

**自动化机制**：场景×关系×3-5 条关键事实 → LLM 生成五个版本台词 → 语气微调旋钮（可填对方性格猜测）→ 一键复制到微信/短信/邮件；脱敏关系档案沉淀。

**操作描述**：选场景（分手挽回/向爸妈道歉/拒绝借钱/离职告别/表白）→ 填关键事实 → 生成五个版本 → 挑顺眼的复制发出；单次 9.9 元，月卡 19 元。

**合法性**：纯文案话术建议，开屏明示"非专业心理咨询"；内容安全护栏过滤骚扰/欺凌/辱骂指令；不采集聊天记录，仅处理用户主动输入。

**迭代方向**：按关系阶段（吵架后/冷战/复合）细分场景库；"给前任的生日祝福""给领导的台阶话术"等垂类模板包。

**操作描述**：录入你的人生第一次 → AI 生成专属纪念卡 → 数字版 9.9 元收藏，实体卡套/卷轴 39-59 元寄送，凑齐 N 张可合成"人生大事记"海报。

**合法性**：用户自述事件+自有照片，无第三方肖像；AIGC 图片/文案加显式标识；情绪标签按最小必要处理、可删除。

**迭代方向**：按年龄里程碑自动提醒（18 岁/毕业/入职/生子）；"给孩子存第一次"家长订阅模式。
